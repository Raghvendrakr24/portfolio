Common Questions

Frequently Asked Questions

Why did you build this with only HTML and CSS? +

Starting with only HTML and CSS builds an unshakeable understanding of the web's foundations. Modern CSS is capable of layout systems, responsive designs, theme toggles, and smooth animations all without running heavy JavaScript.

How does the theme toggle work with no JavaScript? +

It uses the power of modern CSS! A hidden checkbox at the top of the HTML document is linked to the sun/moon button. When clicked, CSS detects :has(#theme-toggle:checked) and immediately swaps the color variables for the whole page.

Are you available for freelance projects or internships? +

Yes! I am always excited to collaborate on new web projects, contribute to open-source, or learn from senior developers on a growing team.

What technologies will you learn next? +

After solidifying pure HTML & CSS, I plan to dive into modern JavaScript (ES6+), working with APIs, and creating interactive web applications.
